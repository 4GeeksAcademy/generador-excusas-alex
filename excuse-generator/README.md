# Excuse Generator

Este proyecto es un generador de excusas aleatorias que puede ser utilizado para cualquier situación en la que necesites una excusa rápida y divertida.

## Estructura del Proyecto

El proyecto tiene la siguiente estructura de archivos:

```
excuse-generator
├── src
│   ├── index.js          # Punto de entrada de la aplicación
│   └── utils
│       └── excuses.js    # Funciones para generar excusas
├── package.json          # Configuración de npm
├── .gitignore            # Archivos y carpetas a ignorar por git
└── README.md             # Documentación del proyecto
```

## Instalación

Para instalar las dependencias del proyecto, ejecuta el siguiente comando en la raíz del proyecto:

```
npm install
```

## Uso

Para ejecutar la aplicación, utiliza el siguiente comando:

```
npm start
```

Esto iniciará la aplicación y podrás comenzar a generar excusas.
